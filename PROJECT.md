# Israel Municipal Waste Dashboard — Project Definition

Working name: **מדד הפסולת** (Israel Waste Index) — final name TBD.

## Mission

A free, public, Hebrew-first website that shows every Israeli local authority's real waste numbers — how much waste it produces, how much is recycled vs. landfilled, and how it trends against the national 2030 targets. The data exists but is buried in CBS Excel publications, ministry PDFs, and Knesset reports. No interactive public dashboard currently exists (verified July 2026). Making it visible creates public pressure, media material, and credibility for the builders in Israel's waste sector.

## Why this matters (context)

- Israel landfills ~76% of its ~6.4M tons/year of municipal waste (2024, Knesset Research Center).
- Government strategy commits to 20% landfilling / 54% recycling by 2030 — a huge, publicly-committed gap.
- Israel ranked 20th of 22 reporting OECD countries on recycling (25.3% in 2023) vs. OECD average ~57%.
- Non-reporting is itself a headline finding the dashboard should surface: in the CBS annual waste survey, 4-29 of ~255-257 local authorities go unreported each year depending on the year (2024: 18 of 257). (Correction, 2026-07-23: an earlier draft of this doc cited "~120-125 of ~255 report," sourced to a 2008 Knesset Research Center report about compliance with a since-superseded Ministry of Environmental Protection regulatory reporting requirement — a different reporting system entirely, 18 years stale. See data/CONFLICTS.md.)
- Best large cities (2024): Bat Yam 39.8%, Holon 38.7%, Ramat Gan 37.8%, Jerusalem 37.4%, Tel Aviv-Yafo 36.5%.

## Audience

1. Journalists and environmental NGOs (Adam Teva V'Din, Zalul, Life & Environment umbrella) — need rankings and trends they can cite.
2. Residents — "how does my city rank?"
3. Municipal sustainability staff — benchmarking against peers.
4. The builders (Adina + partner) — a calling card for future waste-sector ventures (municipal data products, ESG consulting).

## Data sources (start here)

| Source | What it has | Format | Notes |
|---|---|---|---|
| CBS "הרשויות המקומיות בישראל" annual publication | Per-authority waste tons, kg/capita/day, % recycled, by year | Excel + PDF, one publication per year | Primary source. Check cbs.gov.il for the Excel appendix tables, not just the PDF |
| CBS environment statistical abstracts | National totals, treatment breakdown | Excel | For national trend line |
| data.gov.il | Search "פסולת", "מיחזור", "הטמנה" | CSV/XLSX/API | Coverage unknown — audit in Phase 1 |
| Ministry of Environmental Protection (gov.il) waste pages | National facts, landfill levy rates, policy targets | Web pages, PDFs | Source for 2030 targets and levy history |
| Knesset Research & Information Center (מרכז המחקר והמידע) reports | Periodic waste reports w/ recent data (e.g., Feb 2026 report with 2024 data) | PDF, Hebrew | Most current numbers often appear here first |
| Individual municipality reports | Annual waste/recycling reports some cities publish | PDF | Optional supplement; inconsistent |
| OECD environment statistics | International comparison | CSV/API | For the "Israel vs. OECD" panel |

Rule: **every number displayed on the site must link to its primary source.** Credibility is the entire product.

## Data model (target schema)

One tidy table, roughly:

```
authority_id      # CBS authority code (סמל רשות) — the canonical join key
authority_name_he
authority_name_en
district, population, socioeconomic_cluster   # from CBS, for context/normalization
year
total_waste_tons
kg_per_capita_day
pct_recycled
pct_landfilled
pct_other_recovery   # waste-to-energy etc., if reported
reported             # boolean — did the authority report at all this year
source_url, source_name
```

Store as versioned CSVs in the repo (`data/raw/` for downloads as-is, `data/processed/` for clean output). No database needed.

## Tech stack (recommendation)

- **Pipeline:** Python (pandas, openpyxl; pdfplumber only if forced to parse PDFs). Scripts in `pipeline/`, runnable end-to-end with one command. Deterministic: raw files in, clean CSV out.
- **Site:** plain static HTML/CSS/JS + Chart.js. **No frameworks (no React/Astro/Next), no npm build chain, no backend, no database.** Pages are generated by a small Python build script (~100–200 lines) that stamps out HTML from the processed CSV. Rationale (longevity-first, per IndieWeb principles): the output must be dumb static files anyone could rehost in five minutes, and the generator must be trivial enough to rewrite from scratch if it rots. Maintainer budget is a few hours/year — every dependency is a liability. Data ships as static JSON/CSV generated at build time.
- **Hebrew/RTL first**, English toggle later. All UI text in a strings file to make translation easy.
- **Map:** optional; Israel authority boundaries GeoJSON exists (CBS/govmap). Rankings table + city search deliver most of the value; map is a v2 nice-to-have.
- **Hosting:** GitHub Pages or Vercel free tier. Custom domain (~₪50/yr).
- **Repo:** public on GitHub — open data + open source strengthens the advocacy angle.

## Site features

### v1 (launch)
1. Ranked, sortable, searchable table of all authorities: % recycled, kg/capita, trend arrow vs. previous year. Filter by district and by population size class (comparing Tel Aviv to a 3,000-person council is misleading).
2. Authority detail view: multi-year trend chart, vs. national average, vs. 2030 target line.
3. National overview: total waste over time, landfill vs. recycling split, gap-to-2030-target graphic, Israel vs. OECD.
4. "Wall of silence": authorities that don't report at all.
5. Methodology page: every source, every calculation, known data caveats, last-updated date.
6. Share/embed-friendly: each authority has its own URL anchor; og-image cards if cheap to add.
7. Atom/RSS feed (`feed.xml`): entries for data updates and notable findings ("2025 CBS data added", "authority X stopped reporting"). Nearly free to generate in the build script; journalists and NGO staff still live on RSS, and it feeds the future newsletter direction.

### v2 (later, only if v1 gets traction)
- English version, map view, downloadable dataset page, annual auto-update pipeline, per-authority historical PDF archive, food-waste/composting-specific layer.

## Phases & acceptance criteria

**Phase 1 — Data audit (first session).**
Download every candidate source; produce `data/SOURCES.md` documenting what exists per year, per authority, in what format, with URLs. Decide year range (aim: 2015→latest).
*Done when:* we know exactly which years × authorities × metrics are obtainable and from where.

**Phase 2 — Pipeline (1–2 sessions).**
Parse all sources into the schema above. Handle: Hebrew header rows, merged cells, authority name variants (use CBS authority codes as canonical key), missing years.
*Done when:* one command regenerates `data/processed/waste.csv`; spot-checks of ≥10 authorities × 2 years match published figures exactly; row counts and totals reconciled against national figures.

**Phase 3 — Dashboard (1–2 sessions).**
Build v1 features 1–5.
*Done when:* site runs locally, renders correctly in RTL, works on mobile, every figure traceable to a source link.

**Phase 4 — Verify & launch (1 session).**
Full number-by-number audit vs. sources (worth a fresh-eyes subagent/second pass). Buy domain, deploy, add analytics (Plausible or GoatCounter — privacy-friendly). Prepare a 1-page press note with the 3 most newsworthy findings.
*Done when:* live on custom domain; audit log committed; press note drafted.

Estimated total: **12–18 hours of human time, 3–4 weeks elapsed as a side project.** Fully doable remotely.

## Risks & mitigations

- **CBS files messier than expected / PDF-only years** → accept a shorter year range for v1 rather than stall; PDFs are Phase-2-optional.
- **Definitional inconsistencies** (what counts as "recycling" varies by source/year) → pick one primary source per metric-year; document all conflicts on the methodology page rather than silently reconciling.
- **Authority name matching** → always join on CBS authority code, never on name strings.
- **Stale data accusations** → prominent "data as of" stamp; "wall of silence" reframes missing data as the finding.
- **Political sensitivity** → publish numbers + sources only; keep editorializing to the press note, not the site.

## Success metrics

- Launched and live within ~a month of starting.
- Cited/linked by ≥1 journalist or NGO within 3 months.
- ≥3 conversations with waste-sector people (municipal staff, NGOs, companies) triggered by the site — this is the real goal: sector credibility and network for the founders' next venture.
